Mini Project Abstract Presentation (10 slides) — DayTone
Presentation date: 01/07/2026

Slide 1 — Title
- DayTone: AI-Powered Mental Wellness Tracker
- Abstract / Mini Project Presentation
- Name / Roll No / Department (add your details)

Slide 2 — Problem Statement
- Mental health check-ins are often inconsistent and hard to track over time.
- Users need a simple way to log daily mood and understand patterns.
- Opportunity: use AI to analyze notes and predict burnout risk early.
- Goal: a platform that turns daily input into insights + actionable suggestions.

Slide 3 — About the Project (What we built)
- Web application for daily mood logging and wellness dashboard.
- Features: mood history, streaks, heatmap visualization, and PDF/CSV reports.
- Personalized recommendations based on risk level and user behavior.
- Admin panel to view platform analytics and manage user content.

Slide 4 — Existing System (Why current solutions are limited)
- Manual tracking apps typically offer basic journaling but limited analysis.
- Many solutions do not combine:
  - sentiment from journal text
  - pattern-based burnout prediction
  - actionable DOs/DON’Ts
  - strong data export/reporting for progress monitoring
- DayTone focuses on insight + visualization + automation.

Slide 5 — Proposed Solution (How DayTone works)
- User registers and logs mood daily (mood, sleep, stress, social, activity, notes).
- Notes are processed using NLP sentiment scoring.
- ML/rules compute burnout risk (Low/Medium/High).
- Dashboard visualizes trends; suggestions update after each log.
- Reports enable progress tracking and sharing.

Slide 6 — Technologies Used (Backend + Data)
- Backend: Flask (MVC-style routes + Jinja templates)
- Database: SQLAlchemy ORM with SQLite for development
- Security: CSRF protection (Flask-WTF), secure sessions, security headers (Flask-Talisman)
- Rate limiting for login protection (Flask-Limiter)

Slide 7 — Technologies Used (AI/ML + NLP)
- NLP: NLTK VADER sentiment analysis for journal notes
- ML: scikit-learn classification models
  - Decision Tree, Logistic Regression, Random Forest
- Training uses synthetic dataset generation for privacy-safe demonstration
- Prediction includes confidence + fallback rule-based logic

Slide 8 — Technologies Used (Frontend Visualization)
- Charts: Chart.js for mood/sleep/stress dashboard graphs
- Heatmap: D3.js calendar heatmap (GitHub-style wellness grid)
- 3D UI: Three.js “Mood Orb” with shaders for mood visualization
- Responsive UI styling: Bootstrap + custom CSS themes

Slide 9 — Key Output/Modules (Brief work highlights)
- Mood logging: validated forms + sentiment scoring + burnout prediction
- Suggestions engine: rule-based DO/DON’T recommendations tied to user logs
- Exports/Reports:
  - CSV streaming export
  - PDF report generation (ReportLab)
- Admin analytics: platform statistics and user drill-down management

Slide 10 — Conclusion / Impact
- DayTone helps users consistently track well-being with AI-enhanced insights.
- Provides early burnout risk awareness + personalized actions.
- Clear visual trends improve self-reflection and goal setting.
- Future scope: improved models, richer analytics, and additional wellness modules.
