# DayTone Burnout Predictor — Model Card

## Model Details

| Field | Value |
|---|---|
| **Name** | DayTone Burnout Predictor |
| **Version** | Retrained on each data update (see `model_meta.json`) |
| **Type** | Decision Tree Classifier (scikit-learn) |
| **Task** | Multiclass classification — Low / Medium / High burnout risk |
| **Input features** | 12 numeric/boolean features (see below) |
| **Output** | Risk label + confidence probability |
| **Fallback** | Rule-based heuristic if model file is missing |

## Intended Use

- **Primary use**: Daily personal wellness self-monitoring for students and knowledge workers.
- **Who it's for**: Individual users who want an automated signal about their burnout risk pattern.
- **Not intended for**: Clinical diagnosis, medical treatment decisions, insurance assessment, or any high-stakes healthcare context.
- **Not a medical device**: DayTone is an informational wellness tool. Any High-risk prediction should prompt self-care or speaking with a trusted person — not be treated as a clinical finding.

## Training Data

| Field | Detail |
|---|---|
| **Source** | Synthetic data generated by `app/ml/generate_data.py` |
| **Size** | ~5,000 training rows + 100 semi-real validation rows |
| **Privacy** | No real user data used in training |
| **Class balance** | Stratified split across Low / Medium / High labels |

### Feature List

| Feature | Type | Description |
|---|---|---|
| `mood_score` | int (1–5) | Self-reported mood today |
| `sleep_hours` | float | Hours slept last night |
| `stress_level` | int (1–5) | Self-reported stress level |
| `activity_done` | bool | Whether physical activity was logged |
| `social_interaction` | int (1–3) | Social engagement level |
| `sentiment_score` | float (−1 to 1) | VADER sentiment of journal note |
| `avg_mood_7d` | float | Rolling 7-day average mood |
| `avg_stress_7d` | float | Rolling 7-day average stress |
| `avg_sleep_7d` | float | Rolling 7-day average sleep |
| `consecutive_bad_days` | int | Consecutive low-mood days this week |
| `mood_variability` | float | Standard deviation of recent moods |
| `is_weekend` | bool | Whether today is Saturday or Sunday |

**No demographic features** (age, gender, occupation) are used in predictions.

## Limitations

1. **Synthetic training data**: The model is trained on algorithmically generated data, not real user measurements. Generalisation to real populations is unknown.
2. **No clinical validation**: The model has not been evaluated by mental health professionals or in a clinical study.
3. **Self-report bias**: All features depend on honest user input; inaccurate entries degrade prediction quality.
4. **Label leakage risk**: Synthetic labels are derived from the same features used for prediction — this inflates apparent accuracy.
5. **Not longitudinal**: The model does not account for long-term trajectory (e.g., months of data).

## Ethical Considerations

- **No demographic features** are used; the model cannot discriminate by age, gender, or occupation.
- **Notes are processed locally** by VADER sentiment analysis — no text leaves the server.
- **Encrypted at rest**: When `ENCRYPTION_KEY` is set, journal notes are encrypted with Fernet symmetric encryption.
- **Explainability**: The app surfaces the top contributing factors (feature-importance-based drivers) for every non-Low prediction.
- **User feedback loop**: Users can mark predictions as accurate or inaccurate; admins can monitor feedback accuracy in the admin panel.

## How to Retrain

```bash
# From the project root with the virtual environment active:
python -m app.ml.train
```

The training script (`app/ml/train.py`):
1. Loads or generates synthetic training data.
2. Trains Decision Tree, Logistic Regression, and Random Forest classifiers with 5-fold cross-validation.
3. Saves the best model to `app/ml/model.pkl` with a timestamped backup.
4. Writes evaluation metrics to `app/ml/model_metrics.json`.
