DayTone Developer APIs

Integrate with DayTone logs or audit the machine learning performance metrics.

GET

/api/heatmap

Fetch daily aggregated mood and burnout risk metrics to render heatmaps.

Request Parameters

Name Type Required Description
year integer No The four-digit calendar year (defaults to the current year).

Response Schema (200 OK)

{
  "2026-07-01": {
    "id": 42,
    "mood_score": 4,
    "burnout_risk": "Low"
  },
  "2026-07-02": {
    "id": 43,
    "mood_score": 2,
    "burnout_risk": "Medium"
  }
}
POST

/api/feedback/<history_id>

Submit user feedback on the accuracy of a specific ML burnout risk prediction.

Header Guard: Requests must send the Content-Type: application/json header.

Request Body Schema

{
  "accurate": true
}

Response Schema (200 OK)

{
  "success": true,
  "history_id": 128
}
